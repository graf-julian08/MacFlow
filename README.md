# MacFlow

Drag any file on your Mac, hold **⇧** (convert), **⌘** (file tools) or **⌃** (file actions) and drop it
on the wheel that appears at the pointer. Native macOS app for Apple silicon, 100 % local.

**Download:** [MacFlow-2.0.0.dmg](https://github.com/graf-julian08/MacFlow/releases/latest) — open it,
drag MacFlow to Applications. The build is not notarized: on first launch open
System Settings → Privacy & Security and click **Open Anyway**.

Documentation, formats, build instructions and known limitations: [MacFlow/README.md](MacFlow/README.md) ·
test report: [MacFlow/docs/TEST_REPORT.md](MacFlow/docs/TEST_REPORT.md)
